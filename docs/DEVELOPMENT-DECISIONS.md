# Реализация ТЗ VLAD SMASH CLUB

## Принятые временные правила

- Онлайн-эквайринга нет. Администратор подтверждает наличные и переводы вне сайта.
- Все денежные величины хранятся целым числом копеек. В интерфейсе суммы вводятся в рублях.
- Новые и существующие пользователи начинают с нулевого депозита. Остатки из внешних таблиц не угадываются и автоматически не импортируются.
- При записи фиксируется текущая цена занятия. Запись и своевременная отмена не изменяют баланс.
- Посещение отмечает администратор после окончания занятия; только отметка «Присутствовал» списывает зафиксированную цену. Повторная отметка не списывает деньги снова.
- Неявка не штрафуется, поздняя самостоятельная отмена запрещена существующей настройкой cancelHours (по умолчанию 12 часов). Штрафы требуют согласования.
- Исправление посещения выполняется отдельной формой с обязательной причиной. Денежное исправление добавляет операцию, не удаляя историю.
- Депозит привязан к зарегистрированному участнику. Гостевые записи без аккаунта не имеют депозита; администратору следует создать аккаунт для учёта его денег.
- По умолчанию запись разрешена при любом балансе. В настройках можно требовать положительный баланс или проверять будущие записи с учётом индивидуального кредитного лимита. Проверка не списывает деньги.
- В кредитном режиме учитываются все активные записи участника. Отмена освобождает доступный лимит. Посещение может создать задолженность; факт посещения не скрывается при недостатке денег.
- Уровень участника назначает администратор. Новые пользователи не имеют уровня.
- Четыре стартовых уровня: Beginner, Beginner+, Amateur, Advanced. Их можно переименовывать, добавлять и архивировать.
- Новый список допустимых уровней настраивается отдельно для каждого занятия. Пустой список означает открытое занятие для всех. Существующие занятия автоматически не закрываются для пользователей.
- Старое поле уровня занятия пока сохраняется для совместимости существующих фильтров и отображения. Оно само по себе не ограничивает запись; ограничения задаёт новый список допуска.
- Все занятия видны. Сервер проверяет допустимость записи по уровню; администратор может вручную записать участника вне его уровня и балансового ограничения. Вместимость и пересечения по времени остаются обязательными.
- На экранах баланса показаны последние 200 операций. Все операции продолжают храниться в базе.

## Где пользоваться

Клиент: «Личный кабинет» → «Мой баланс».

Администратор: «Клиенты» → кнопка суммы баланса → пополнение, возврат на депозит, корректировка, уровень и кредитный лимит.

Администратор: «Настройки» → правила баланса и справочник уровней.

Администратор: «Расписание» → «Допуск по уровням» у занятия.

Администратор: «Записи» → отметка посещения / исправление посещения с причиной.

## Обновление

Перед обновлением рабочей базы сделать согласованную резервную копию SQLite вместе с учётом WAL (через SQLite backup или при остановленном приложении). Не копировать только club.db работающей WAL-базы.

Команды после установки зависимостей:

```sh
npm run build
npm run db:migrate
npm start
```

Миграции 007–008 добавляют таблицы и поля. Старые пользователи, записи и расписание сохраняются. Для существующих записей фиксируется цена занятия на момент миграции. Старые посещения автоматически не списываются задним числом.

## Оставшаяся часть расширенного ТЗ

Это первый рабочий блок доработки, а не завершение всего нового ТЗ. Отдельной реализации требуют: гибкие роли владельца/тренера/партнёра и управление ими; персональные рабочие интервалы тренеров и отдельный календарь слотов; произвольные форматы тренировок; финансовые отчёты и экспорт; лист ожидания; внешние уведомления; редактирование всех презентационных блоков; блокировка аккаунтов; Telegram и расширенный профиль. Для интеграций нужны аккаунты сервисов и согласованные каналы. Секреты не хранить в репозитории.
